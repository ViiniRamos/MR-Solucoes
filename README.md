# MR Soluções Elétricas

Site institucional para a MR Soluções Elétricas, empresa de serviços elétricos residenciais e comerciais.

## Sobre o projeto

O site tem como objetivo apresentar a empresa, mostrar os serviços oferecidos, exibir um portfólio de trabalhos realizados e facilitar o contato com clientes através de um formulário de orçamento assistido por inteligência artificial.

## Funcionalidades

- **Páginas**: Home, Sobre, Trabalhos e Contato, cada uma com sua própria rota.
- **Formulário de orçamento com IA**: o cliente descreve o problema elétrico e a IA (Google Gemini) analisa a descrição e gera automaticamente:
  - Causa provável do problema
  - Materiais provavelmente necessários
  - Nível de urgência (baixa, média ou alta)
  - Faixa de orçamento estimada
- **Notificação automática**: o resultado da análise é enviado por e-mail para o responsável pela empresa assim que o cliente envia o formulário.
